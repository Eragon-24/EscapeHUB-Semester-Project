# Contributing to EscapeHub

1. Pick an agreed GitHub Issue before starting work.
2. Create a short-lived branch from `main`.
3. Keep changes focused on the issue.
4. Add or update automated tests for changed behavior.
5. Open a Pull Request and link the issue.
6. Request review from another team member.
7. Merge only after the required review and successful CI checks.

Do not commit credentials, API keys, `.env` files or personal data. Update documentation when behavior or setup changes.
